# first-pr-demo

Mein erstes GitHub Repository — ein Lernprojekt zum Üben des Pull-Request-Workflows.

## Was ist das hier?

Dieses Repository dient als Spielwiese, um den GitHub-Workflow zu verstehen:
Änderungen auf einem Branch vornehmen, einen Pull Request öffnen und mergen.

## Workflow

```
# 1. Branch erstellen
git checkout -b mein-feature

# 2. Änderungen machen und committen
git add .
git commit -m "Beschreibung der Änderung"

# 3. Branch pushen
git push origin mein-feature

# 4. Pull Request auf GitHub öffnen
gh pr create
```
